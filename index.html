01 / ҮЙЛЧИЛГЭЭ

Өөрт тохирохоо сонго.

Багцын хэмжээ, үнэ болон гүйцэтгэх хугацааг захиалга хийхээс өмнө шалгаарай.

Санамж: үйлчилгээний багцын хэмжээ болон хүргэх хугацаа бүтээгдэхүүн бүр дээр тодорхой бичигдсэн байх ёстой. Энэ загварын анхны үнэ жишээ бөгөөд админ хэсгээс өөрчилж болно.

02 / ЗАХИАЛГЫН ЯВЦ

Гурван алхам. Ингээд боллоо.

АЛХАМ 01

Үйлчилгээгээ сонго

Платформ, үйлчилгээ болон тохирох багцаа сонгон сагсанд нэмнэ.

АЛХАМ 02

Захиалгын мэдээлэл

Холбоо барих мэдээлэл болон үйлчилгээ хүргэх нийтийн профайл эсвэл постын холбоосоо оруулна.

АЛХАМ 03

Төлбөрөө баталгаажуул

QPay төлбөрийн хүсэлт үүсгэж, төлбөрийн төлөвийг баталгаажуулсны дараа захиалга боловсруулагдана.

Төлбөрийн чухал мэдээлэл: QPay-ийн бодит төлбөрийн холбоос үүсгэх, төлбөр шалгахын тулд QPay мерчантын эрх, backend сервер болон API мэдээлэл шаардлагатай. Энэ HTML загвар дангаараа бодит төлбөр хүлээн авахгүй.
03 / ИЛ ТОД БАЙДАЛ

Итгэлцэл бол брэндийн суурь.

Хэрэглэгч худалдан авахаасаа өмнө юу авч байгаагаа, хэдийд авах болон ямар нөхцөл үйлчлэхийг мэддэг байх хэрэгтэй.

✓Үнэ, багцын хэмжээ, гүйцэтгэх хугацааг тодорхой харуулах
✓Хэрэглэгчийн нууц үгийг хэзээ ч шаардахгүй байх
✓Буцаалт, цуцлалт болон дэмжлэгийн нөхцөлийг урьдчилан мэдээлэх
✓Платформын дүрэмд нийцсэн үйлчилгээ сонгох
04 / ТУСЛАМЖ

Түгээмэл асуулт

Захиалга шууд хийгдэх үү?

Энэ хувилбар нь веб загварын туршилтын горим. Бодит захиалга хүлээн авахын тулд backend болон админ сервер холбох шаардлагатай.

QPay-р төлбөр хийж болох уу?

QPay холбох боломжтой. Үүний тулд мерчантын эрх, API мэдээлэл болон сервер талын төлбөр баталгаажуулалт хэрэгтэй. Нууц түлхүүрийг веб хуудасны код дотор байрлуулж болохгүй.

Нууц үгээ өгөх шаардлагатай юу?

Үгүй. Захиалга боловсруулахад шаардлагатай нийтийн холбоос болон холбоо барих мэдээлэл л авна.
